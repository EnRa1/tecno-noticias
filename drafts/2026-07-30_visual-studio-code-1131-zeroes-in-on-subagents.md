Microsoft estrena mejoras en Visual Studio Code 1.131

## ARTICULO
El ecosistema de desarrollo de software recibió el pasado 29 de julio una actualización significativa. Los programadores ya pueden implementar las **mejoras en Visual Studio Code 1.131**, una versión que busca refinar la interacción con la inteligencia artificial y optimizar la edición de documentos técnicos en entornos Windows, Linux y macOS.

Esta entrega no es una actualización menor, sino un paso firme hacia un entorno de desarrollo más fluido y menos dependiente de extensiones externas. El equipo de ingeniería ha puesto especial énfasis en la transparencia de los procesos automatizados y en la versatilidad de la interfaz de usuario.

### Transparencia total en el flujo de subagentes

Una de las incorporaciones más destacadas dentro de las **mejoras en Visual Studio Code 1.131** se encuentra en la ventana de Agentes. Ahora, los desarrolladores disponen de una visibilidad sin precedentes sobre lo que ocurre "bajo el capó" cuando un subagente de IA está operando.

Anteriormente, entender el estado de una tarea secundaria requería abrir hilos de conversación específicos. Con esta actualización, la interfaz principal muestra en tiempo real qué modelo está utilizando el subagente, cuánto tiempo lleva en ejecución y exactamente qué herramienta está invocando. Esta capacidad de monitoreo permite detectar cuellos de botella en la generación de código sin interrumpir el flujo de trabajo principal.

### Programación por voz y edición híbrida

La flexibilidad en la entrada de datos es otro pilar de las **mejoras en Visual Studio Code 1.131**. Microsoft ha introducido una vista previa de la función de dictado integrada. Esto significa que ya no es obligatorio instalar la extensión específica de voz para transcribir instrucciones en el editor, el chat o la terminal.

Lo más innovador de este sistema experimental es la unificación de la sesión de voz. Al compartir el micrófono y la sesión entre las tres superficies, el software evita grabaciones solapadas y garantiza que el texto aparezca exactamente donde el usuario lo necesita. Es un avance que [más detalles sobre las funciones inteligentes](https://visualstudiomagazine.com/articles/2026/07/29/vs-code-1131.aspx) sugieren como el futuro de la accesibilidad y la ergonomía.

Por otro lado, la ventana de Agentes ahora cuenta con un editor híbrido de Markdown. Esta funcionalidad permite visualizar y modificar archivos Markdown en el mismo lugar, sumando la posibilidad de añadir comentarios que la IA puede interpretar y ejecutar. La transición entre el editor de texto tradicional y esta nueva modalidad es instantánea mediante el comando "Reopen editor with".

### Un entorno más inclusivo y eficiente

La experiencia de usuario para personas que utilizan lectores de pantalla también forma parte de las **mejoras en Visual Studio Code 1.131**. La terminal integrada ha sido refinada para que los usuarios de tecnologías de asistencia puedan leer la salida a su propio ritmo, incluso mientras se generan nuevos datos en tiempo real.

Mediante la configuración de la posición del cursor en la vista accesible, el sistema ahora permite que el contenido nuevo llegue sin desplazar involuntariamente el foco de lectura. Además, las notificaciones de estado ARIA ahora son menos intrusivas, evitando alertas asertivas que solían interrumpir la síntesis de voz del programador.

### Evolución constante del editor

El despliegue de las **mejoras en Visual Studio Code 1.131** confirma la tendencia de Microsoft por convertir a su editor en un centro neurálgico donde la IA no solo asiste, sino que es totalmente auditable. Según se desprende de [el registro oficial de cambios](https://daily.dev/blog/visual-studio-code-1-131), la integración de estas herramientas experimentales es solo el inicio de una fase de pruebas más ambiciosa.

Es importante recordar que, al ser muchas de estas funciones de carácter experimental, su activación requiere una revisión de las configuraciones de usuario. Sin embargo, la estabilidad mostrada en esta versión sugiere que pronto formarán parte del núcleo estable del programa.

Para quienes buscan maximizar su productividad, explorar las [mejoras en Visual Studio Code 1.131](https://www.infoworld.com/article/4203128/visual-studio-code-1-131-zeroes-in-on-subagents.html) es esencial. La capacidad de alternar entre herramientas de voz, edición visual de documentos y supervisión de agentes de IA coloca a este editor un paso por delante de la competencia directa en el mercado de IDEs ligeros.
